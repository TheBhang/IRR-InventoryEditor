Big usability update.

**Download `IRR-InventoryEditor.zip`, unzip, run `IRR-InventoryEditor.exe`.**

### New
- **Move between containers**: drag items between stash pages, backpack, rig and pouch, or right-click → *Move to* (works between stash and loadout too).
- **Stash – all pages** view: the main stash and every stash page side by side.
- **Undo / Redo** (Ctrl+Z / Ctrl+Y) for every change, including base, reputation and presets.
- **Multi-select**: Ctrl+click or drag a box on empty space; Delete / Repair / Move apply to all.
- **Search** (Ctrl+F): highlights matching items in the grid and the tree, Enter jumps to the next one.
- **Add item**: set the stack count by typing or with a slider.
- **Weapon parts**: attach, swap or remove parts – compatibility is learnt from what the game itself mounts; detach a part to the stash.
- **Weapon presets** (Gunsmith): browse, rename, duplicate, delete.
- **Backups window**: list backups and restore one with a click (current saves are backed up first).
- **Change detection**: warns if the game wrote the saves while the editor was open.
- **Update check** in *About*.

### Improved
- Sharp UI on 125 % / 150 % displays (DPI-aware), bigger and clearer layout.
- Grid zoom (Ctrl+wheel or − / + buttons).
- Gold selection in lists, dark scrollbars in tables.
- Builds and releases are now made automatically by GitHub Actions.

Unofficial fan tool, not affiliated with Games Farm. Close the game before editing.
